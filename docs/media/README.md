# docs/media

Demo outputs of the M1 pipeline (T-007), committed because they are small:
- `m1_<name>.gif`: optimized demo GIFs (each <= 4 MB), referenced from the README.
- `m1_<name>_compare.jpg`: side-by-side input and final painting (<= 500 KB).
- `m1_results.md`: metrics table, generated by `scripts/make_m1_demos.py` from the stored metrics (do not edit by hand).
- `m2_<name>.gif`, `m2_<name>_vs_m1.gif`, `m2_<name>_compare.jpg`, `m2_results.md`: the M2 demos (T-018), Paint Transformer
  alone, side by side with the M1 baseline (each GIF <= 4 MB), input | M1 | PT, and the metrics table; generated by
  `scripts/make_m2_demos.py` (do not edit by hand).
- `pt_train_curve.png`: validation loss of the Paint Transformer training run (T-013), a short 3000-step GPU run; see
  `docs/design/paint_transformer.md`, section 13.
- `pt_inference_layers.jpg` and `pt_inference_refine.jpg`: the layers of the Paint Transformer inference and the effect of the
  per-patch refinement (T-015); see `docs/experiments/pt_inference.md`.
- `pt_repro_fig5.jpg`, `pt_repro_fig6.jpg`, `pt_repro_fig7.jpg`: Figures 5 to 7 of the Paint Transformer paper, reproduced on our
  models (T-016); see `docs/experiments/pt_reproduction.md` for the verdicts (Fig. 5 and 7 reproduced, Fig. 6 partly).
- `pt_training_official_recipe.png` and `pt_training_long.png`: training and validation curves of the three-seed runs of the
  official schedule and the stretched schedule (T-014); see `docs/experiments/pt_training.md`.

Nothing else is committed here (the inputs are in `data/raw/`, the full outputs in `outputs/`).
