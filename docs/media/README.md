# docs/media

Demo outputs of the M1 pipeline (T-007), committed because they are small:
- `m1_<name>.gif`: optimized demo GIFs (each <= 4 MB), referenced from the README.
- `m1_<name>_compare.jpg`: side-by-side input and final painting (<= 500 KB).
- `m1_results.md`: metrics table, generated by `scripts/make_m1_demos.py` from the stored metrics (do not edit by hand).

Nothing else is committed here (the inputs are in `data/raw/`, the full outputs in `outputs/`).
